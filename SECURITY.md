# Security Policy

## Supported Versions

Currently and for a while version under alpha 4.0 are being supported as we are only on V1.5-Alpha


| Version | Supported          |
| ------- | ------------------ |
| > 4.0   | :x:                |
| < 4.0   | :white_check_mark: |

## Reporting a Vulnerability

To report a vulnerability, make an issue and describe what it is, what version it is in and possible fixes
